
Trabajo Práctico Integrador
Arquitectura y Sistemas Operativos

Proyecto
Virtualización de un sistema operativo Linux mediante Oracle VirtualBox.
Objetivo
Implementar un entorno virtualizado utilizando VirtualBox e instalar Linux Mint como sistema operativo invitado.

Herramientas utilizadas
- Oracle VirtualBox.
- Linux Mint 22.3 XFCE.
- Python 3.12.3.

Programa desarrollado
Se desarrolló un programa en Python que muestra información del sistema operativo virtual, la versión, el nombre del equipo, los procesadores disponibles, la versión de Python y el directorio actual.

Ejecución
Para ejecutar el programa desde una terminal de Linux:

    python3 sistema.py
